# Changelog

## 0.1.0 — 2026-11-10

First consolidated public release, based on the functionality of development version **0.1.5**. The numbering restart does not remove features.

- YouTube Music song search and MusicBrainz artist/album browsing.
- ListenBrainz private, public and generated playlists; playlist editing, track additions and loved tracks.
- Optional scrobbling and saved account sessions.
- Playlist counts, token Show/Hide and paste/bridge readiness fixes.
- Concise README and separate build instructions.

### Version numbering reset

The earlier 0.1.0–0.1.5 builds were development prototypes. Their published releases and tags are retired in favour of this new **0.1.0**. Git commit history is retained, and the pre-reset releases are archived locally by the maintainer.

Existing prototype installations may display a downgrade confirmation when importing this release. The plugin identity and login storage are unchanged.

### Development milestones before the reset

- **Prototype 0.1.0:** initial Kotlin/JS port for Spotube V6.
- **Prototype 0.1.1:** fixed manifest capabilities and metadata selection.
- **Prototype 0.1.2:** English interface and revised sign-in lifecycle.
- **Prototype 0.1.3:** YouTube Music search and MusicBrainz matching for saves.
- **Prototype 0.1.4:** corrected playlist counts.
- **Prototype 0.1.5:** fixed pasted-token sign-in readiness and added Show/Hide.
